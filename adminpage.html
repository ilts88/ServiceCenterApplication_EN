You've logged into the repair request management system. To view detailed information about a request, click the "open" button next to the relevant request. The menu that opens will display all available information about the request, as well as an interface for changing the request status and adding a service center comment.

You must schedule repairs for new requests promptly and complete them within the specified deadline. We remind you that, according to our company rules, repairs must be scheduled within 7 days of request creation and completed within 30 days of request creation. Two days before the deadline, the system will warn you, highlighting in red the time of request creation for which the deadline for assigning the appropriate status is about to expire. If you are late scheduling or completing a repair, the system will highlight in red all fields in the request for which the deadline for assigning the appropriate status has expired as a warning.

When changing the status of request, you must add a service center comment. When scheduling a repair, you must include the date and time of the repair, as well as the address of our repair facility. If an air conditioner needs repair, specify that the repair will be performed at the customer's home (for privacy reasons, please do not include the customer's address or any other personal information in the comment, as this could be obtained by attackers through brute-force enumeration of request IDs). When the repair is completed, you must indicate the date and location of the repair, as well as a brief description of the problem and how it was resolved.

The system provides an option to reject a repair request; however, this option should be used as rarely as possible. A request is typically rejected when it has been incorrectly completed and contains errors in two or more fields (for example, when the reported issue is unclear and the serial number provided does not exist).If only one field contains incorrect or incomplete information, you must contact the person who submitted the request and ask for clarification. If you are unable to obtain the required information, you may reject the request. In such cases, politely advise the customer to submit a new request and clearly explain the mistakes that caused the original request to be rejected.

According to the rules, each request must be stored in the system for at least 180 days. After this period, the system will offer to delete requests with the "resolved" and "rejected" statuses, making the "delete" button available next to these requests. The system also offers the option to delete all requests that meet the deletion rules at once. To do this, click the "delete all old requests" button.
